
# Drone Management System

A Python-based Drone Management System developed using Object-Oriented Programming (OOP) principles.

## Project Overview

This project aims to manage different types of drones and their missions through a modular Python application.

## Features

- Drone management (Add, List, Update, Delete)
- Different drone types
- Drone status management
- Mission management
- JSON-based data storage
- Object-Oriented Programming principles

## Project Structure

```text
model/
├── Repositories/
│   └── json_repository.py
├── drone.py
├── exceptions.py
├── mission.py
├── mission_service.py
├── service.py
├── status.py
└── main.py
```
